# 💰 Expense Tracker

A modern personal finance tracker built with React + Vite + Zustand + Tailwind CSS.

## ✨ Features

- 📊 Dashboard with summary cards
- 💸 Full CRUD for transactions
- 🔍 Advanced filters (search, type, category, month)
- 📈 Reports with 3 chart types (pie, bar, line)
- 💾 LocalStorage persistence (backend-ready)
- 📱 Fully responsive (mobile drawer)
- 🌙 Clean, modern UI
